4. 우리 몸의 구조와 기능과학실 장기 탐정단! 그림자의 정체를 맞히고 인체 모형을 완성해요.

  • 스테이지마다 목숨 ❤️ 3개가 있어요. 시간 제한은 없고, 난이도가 갑자기 올라가지도 않아요.

스테이지 1 · 전기 회로

배터리와 전선을 연결해 전구를 켜요

화살표가 초록색에 있을 때 클릭하세요. 성공할 때마다 초록 구간이 다른 곳으로 옮겨 가요. 화살표 속도와 초록 크기는 끝까지 그대로예요. 5번 연속 성공하면 전구가 켜지고, 잘못 누르면 목숨이 줄고 연속 기록이 0이 돼요.

연속 성공 0 / 5

판정바를 직접 클릭해도 돼요

전구에 불이 켜지려면 전지의 (+)극 → 전선 → 전구 → 전선 → (−)극으로 끊긴 곳 없이 이어진 닫힌 회로가 되어야 해요.

스테이지 2 · 빛의 굴절

손전등으로 움직이는 물고기를 비춰요

빛은 공기에서 물로 들어갈 때 수면에서 꺾여요. 꺾이는 방향을 생각해 위치와 각도를 맞추고, 물고기가 지나가는 순간 「빛 비추기」를 누르거나 화면을 클릭하세요. 기회는 3번이에요.

200
25°
남은 기회 3 / 3
입사각 25.0° 굴절각 18.5° 물의 굴절률 1.33

빛이 공기에서 물로 비스듬히 들어가면 수면에 세운 수직선(법선) 쪽으로 꺾여요. 그래서 굴절각이 입사각보다 작아지고, 물속 물체는 실제보다 떠 보여요. 점선은 빛이 꺾이지 않았다면 갔을 길이에요.

스테이지 3 · 자석과 전자석

전자석 뽑기 기계로 철 물건을 건져요

  1. ① 기계 조립
  2. ② 물건 위에서 멈추고 집기
  3. ③ 통 위에서 떨어뜨리기

① 부품 연결

전자석 뽑기 기계가 되도록 올바른 순서로 부품을 클릭해요.

② 전류 세기

약강 2

전자석이 원하는 곳에 오면 「멈추기」나 기계를 클릭해요. 멈춘 다음 스위치를 켜고 끄며 물건을 집고 떨어뜨려요.

통에 담은 철 물건 0 / 3

코일에 전류가 흐르면 철심이 자석이 돼요(전자석). 전자석은 철로 된 물체만 끌어당기고, 플라스틱이나 고무는 끌어당기지 않아요. 전류가 셀수록 전자석도 세지고, 스위치를 끄면 자석의 성질이 사라져 물건이 떨어져요.
